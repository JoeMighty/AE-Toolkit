## 🎬 The Tools

This repository contains 12 dockable utility scripts designed to solve daily pain points for motion designers.

### Workflow & Organization
* **Project Auto-Organizer**: Scans the project bin and automatically files items into neat folders (Audio, Images, Video, Comps, Solids) based on file extensions.
* **Slideshow Builder**: Instantly arranges layers into a sequential slideshow with custom durations, fades, and complex transitions.

### Animation & Keyframing
* **Layer Randomizer**: Randomly shifts the start times of selected layers to create organic, staggered animations.
* **Advanced Sequencer**: Staggers or sequences layers back-to-back with precise frame offsets and ordering controls.
* **Expression Injector**: A quick panel to inject common expressions (Wiggle, Loop Out, Inertia Bounce) into selected properties without typing.
* **Expression Baker**: Automatically finds every single property running an expression on selected layers and natively bakes them into standard keyframes.

### Layout & Design
* **Anchor Point Manager**: A 3x3 grid UI that snaps layer anchor points to 9 different sectors without moving the layer's visual position.
* **Auto Text Box**: Creates a dynamic shape layer that perfectly wraps behind your selected text, automatically resizing when the text changes.

### Text & Subtitles
* **Text Splitter**: Takes a single text layer and duplicates it into separate layers based on individual words or lines.
* **Subtitle Importer**: Reads a standard `.srt` file and generates a text layer with Hold keyframes perfectly synced to the timestamps.

### Color & Styling
* **Master Color Controller**: Links all color properties in selected layers to a single Master Color Null via expressions for global brand updates.
* **Color Palette Extractor**: Samples colors from an image layer and generates a clean 5-color solid shape palette in your composition.

## 📦 Installation

1. Download the `.jsx` file of the tool you want to use.
2. Place the script inside your After Effects `ScriptUI Panels` folder:
   * **Windows**: `C:\Program Files\Adobe\Adobe After Effects <version>\Support Files\Scripts\ScriptUI Panels\`
   * **Mac**: `/Applications/Adobe After Effects <version>/Scripts/ScriptUI Panels/`
3. Restart After Effects.
4. Open the tool by navigating to the **Window** menu at the top of the screen and selecting the script name.
